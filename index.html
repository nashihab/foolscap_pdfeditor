Edit

Hover the page to see what can be changed. Click existing text to retype it in place, or click an existing image to swap it out.

About font matching: if your new wording only reuses letters already present in that line, Foolscap re-embeds the document's own font so the replacement is pixel-identical. Otherwise it falls back to the closest matching standard typeface (same weight and slant) so nothing ever renders as a blank box.
